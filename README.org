* readability-metric

Readability metrics for EPUB books.

** Nix usage

Process a directory of EPUB files to JSON Lines:

#+begin_src shell
nix run . -- --corpus-dir ~/Downloads --output results/downloads-readability.jsonl --jobs 4
#+end_src

Run the test suite:

#+begin_src shell
nix develop -c make test
#+end_src

Build the packaged command:

#+begin_src shell
nix build
#+end_src

** Python usage

#+begin_src shell
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m readability_metric --corpus-dir ~/Downloads --output results/downloads-readability.jsonl
#+end_src

** Output

The default batch processor writes one JSON object per line. Each record includes EPUB metadata, detected language, token counts, vocabulary-growth fit parameters when the book is below the configured size limit, and per-file errors without stopping the whole batch.

For ranking by lexical difficulty, prefer =predicted_unique_words_20k= over the raw slope. It estimates how many unique word forms the model expects in the first 20,000 words, using both the fit slope and intercept. Lower values mean slower vocabulary growth and therefore easier books by this metric. The output also includes =lexical_ease_percentile_by_language=, where 100 is easiest within the same detected language.

#+begin_src shell
jq -r '
  select(.language=="ca" and .status=="ok" and .predicted_unique_words_20k != null)
  | [.lexical_ease_percentile_by_language, .predicted_unique_words_20k, .word_count, .unique_words, (.creator // ""), (.title // "")]
  | @tsv
' results/downloads-readability.jsonl | sort -nr | head -20
#+end_src

The legacy MongoDB path is still available by passing =--database= with =--book= or =--corpus-dir=.

** Chinese Story Ladder Pipeline

Generate a staged set of beginner-level Chinese stories from an EPUB corpus:

#+begin_src shell
python3 story_pipeline.py \
  --corpus-dir ~/haodoo \
  --output-dir ~/haodoo-stories \
  --stages 12 \
  --stage-word-count 8 \
  --min-repetitions 5 \
  --target-ratio 0.98
#+end_src

The output bundle contains:

- `curriculum.json`: ordered stage manifest and quality metrics
- `stage_XX.html`: hidden-text HTML book file with reveal control and audio reference
- `stage_XX.txt`: plain text copy
- `stage_XX.json`: per-stage metadata (coverage, repeats, unknown streak)
- `stage_XX.tts.json`: shell command suggested for text-to-speech

Important defaults are exposed via CLI:

- target known-word coverage before introducing new words (`--target-ratio`, default `0.98`)
- minimum repetitions per new word per stage (`--min-repetitions`, default `5`)
- number of new words per stage (`--stage-word-count`, default `8`)
- max generated sentences per stage (`--max-sentence-count`, default `30`)

`StoryDraft` includes both:
- `known_ratio`: coverage against previously known words
- `known_ratio_with_introduced`: coverage after adding that stage’s new words

This is a practical starter toward a zero-cognate path: you can use the generated HTML for listening-first reading by creating audio with the emitted TTS command, then un-hiding text gradually.


** Mandarin Subtitle Ladder Corpus

For the Chinese ladder project, start with Furretar's Mandarin subtitle archive rather than random OPUS movie subtitles. It is organized around Chinese-dubbed series with matching soft subtitles, so the per-episode profiles are a better source for finding beginner audiovisual candidates.

Clone or download the archive outside this repository, then ingest it:

#+begin_src shell
git clone --depth 1 https://github.com/Furretar/Mandarin-Subtitles-Archive.git ~/Downloads/Mandarin-Subtitles-Archive
scripts/mandarin-subtitles-archive.sh ~/Downloads/Mandarin-Subtitles-Archive
#+end_src

The dedicated source mode skips obvious non-Mandarin tracks such as =jpn=, Japanese, Cantonese, and English subtitle folders/files. It writes per-episode profiles under =results/zh-mandarin-subtitles-archive= and merged frequency rankings to:

- =results/zh-mandarin-subtitles-archive-chars.jsonl=
- =results/zh-mandarin-subtitles-archive-words.jsonl=

Manifest rows include archive-specific metadata such as =collection=, =series=, =season=, =episode_number=, and =subtitle_variant= so recommendations can be grouped by show and dialect/source variant.

Build a watch ladder for a learner profile:

#+begin_src shell
python3 -m subtitle_ladder \
  --manifest results/zh-mandarin-subtitles-archive/manifest.jsonl \
  --learner-profile results/learner-profile.json \
  --output-episodes results/subtitle-ladder-episodes.jsonl \
  --output-series results/subtitle-ladder-series.jsonl \
  --min-coverage 0.95 \
  --target-coverage 0.98
#+end_src

The episode output is sorted by current watchability: =extensive= at 98%+ known-word coverage, =ci= at 95-98%, =assisted= at 90-95%, then =skip=. The series output ranks shows by how many watchable episodes are available contiguously from episode 1, which is the first practical approximation of a curriculum sequence.

* Vocabulary Frequency Pipeline

Extract ranked Chinese characters and words from an EPUB corpus:

#+begin_src shell
python3 -m vocabulary_pipeline \
  --corpus-dir ~/haodoo \
  --output-chars results/zh-chars.jsonl \
  --output-words results/zh-words.jsonl \
  --with-pos \
  --min-count 2 \
  --top 2000 \
  --with-phrases \
  --output-phrases results/zh-phrases.jsonl \
  --phrase-max-length 3 \
  --fetch-images \
  --image-output results/zh-images.jsonl \
  --image-limit 500 \
  --allow-non-open
#+end_src

`--output-chars` and `--output-words` are independent. Use `--chars-only` or `--words-only` to restrict extraction. Add `--with-phrases` plus `--output-phrases` for multi-word phrases, and `--fetch-images` (with optional `--image-limit`) for open-license Wikimedia image lookups. Add `--verbose` if you want per-EPUB progress and final counts like `Scanned N EPUB files: K kept as Chinese, X non-Chinese, Y failed`.

Create per-book profiles first, then merge them into corpus-wide rankings:

#+begin_src shell
python3 -m vocabulary_pipeline \
  --corpus-dir ~/haodoo \
  --output-books results/zh-books \
  --output-chars results/zh-chars.jsonl \
  --output-words results/zh-words.jsonl \
  --min-count 1 \
  --min-cjk-chars 100 \
  --jobs 4 \
  --verbose
#+end_src

Each included book gets `chars.jsonl`, `words.jsonl`, and `book.json` under `results/zh-books/<book-id>/`. The per-book JSONL files use the same schema as the corpus-wide ranking files, so they can be merged into mini-corpora:

#+begin_src shell
python3 -m vocabulary_pipeline \
  --merge-manifest results/my-series.jsonl \
  --output-chars results/my-series-chars.jsonl \
  --output-words results/my-series-words.jsonl \
  --min-count 1
#+end_src

A merge manifest is JSON Lines with one selected book per line, for example `{"book_dir":"results/zh-books/1179-abc123def0"}`. To scope a quiz to a single book or mini-corpus, pass those ranking files to `vocabulary_quiz` with `--chars` and `--words`.

Quiz yourself against the ranked character and word lists:

#+begin_src shell
python3 -m vocabulary_quiz --unit both --chars results/zh-chars.jsonl --words results/zh-words.jsonl
#+end_src

The quiz asks whether you know progressively harder characters or words, then binary-refines around your current level. Use `--unit char` or `--unit word` to test only one list, and `--max-questions` to change the default 30-question cap.

Build book recommendations from your learner profile and per-book profiles:

#+begin_src shell
python3 -m book_recommendations \
  --manifest results/zh-books/manifest.jsonl \
  --learner-profile results/learner-profile.json \
  --output results/book-recommendations.jsonl
#+end_src

The output is sorted by known word coverage first, then known character coverage. Each row includes total/unknown token counts and the most frequent unknown characters and words for that book.

Tag books that appear in the 20th-century Chinese novel top-100 list:

#+begin_src shell
python3 -m book_tags \
  --manifest results/zh-books/manifest.jsonl \
  --ranking-json-dir results/book-ranking-lists/book_rankings_json \
  --output results/book-tags.jsonl \
  --catalog-output results/book-tag-catalog.json
#+end_src

The tag output is separate from `book.json` so external rankings stay auditable and can be regenerated without rewriting per-book profile folders. `--ranking-json-dir` adds downloaded ranking JSON files; omit it to tag only the built-in 20th-century Chinese novel top-100 list.
